Your Field Advisor

A Claude project that knows everything from tonight. Set up once on wifi, then message it from anywhere with signal.

Setup · 3 minutes

  1. Open the Claude app → Projects → New Project. Name it Field Advisor.
  2. Tap the button below to copy the instructions, then paste into the project's Custom instructions.
  3. Download the six documents below (they save to Files), then add them to the project as knowledge.
  4. Test it: "A landslide just blocked us. How do I sync into that story?"
