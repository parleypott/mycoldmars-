Roland J-6 · Field Manual

Beautiful chords,
one small box

Everything you need to make emotional house progressions. Nothing you don't.

The idea in four sentences

The J-6 is a Juno-60 that plays whole chords when you press one pad. A chord set decides which twelve chords live on the twelve pads. A style decides how each chord is performed: held, stabbed, or rolled into an arpeggio. The sequencer records which pads you pressed and loops them.

So the whole instrument is: pick a set, find four pads that sound like a feeling, record them, turn on a style, and ride the filter. That's the entire game.

Panel map · the controls that matter

CHORDChord mode on/off. Lit = each pad plays a full chord. SHIFT+CHORD = choose which chord set (1–100) with the value knob, press CHORD to confirm.
TEMPO/VALUEThe one knob that edits everything. Alone = tempo. In any menu = the value.
SOUNDPick one of 64 Juno sounds: press SOUND, then a step button 1–8. Hold SOUND + step = switch bank (8×8).
PATTERNSame logic: press, then step 1–8. Hold + step = bank. Factory demos fill banks 1–2; banks 3–8 are yours.
▶ / ●Play and record. Press ● then ▶ to record live. Press ● during playback to punch in.
STEPS 1–8Press a step to open it, press a pad to write a chord into it, press again to close. SHIFT+step = jump pages (up to 64 steps).
STYLE / VARNine style banks × twelve variations. Banks 1–2 arpeggios, 3 rhythmic re-triggers, 4–5 house stabs, 6–9 chord and strum phrases. STYLE ON switches the engine on.
HOLDLatches a chord so it keeps sounding hands-free. In step edit: writes a tie so a chord sustains across steps.
FILTERLow-pass cutoff. Your main performance move. SHIFT = resonance.
ENVELOPERelease. Clockwise = chords bleed into each other. SHIFT = attack (soft swells).
DELAYLevel. SHIFT = time. Set d.Syn On in the menu once so it locks to tempo.
REVERBLevel. SHIFT = tail length. Be generous.
KEY pad (A)SHIFT+A = transpose the whole keyboard in semitones. Exit with C.
WRITE (top C)SHIFT+top C = save. Choose Ptn or ALL, confirm with D.
NOTHING AUTO-SAVES. Power off without SHIFT + WRITE and your pattern is gone. Save after every keeper.

First loop · ten minutes

01

CHORD lit. SHIFT+CHORD, dial set 50, confirm. Tempo around 118.

02

STYLE OFF for now. Press pads and just listen. Set 50 is built so every pad flatters every other pad. Find four that ache.

03

Press step 1, press your first pad, press step 1 again. Same for steps 3, 5, 7. SHIFT+F sets the loop length to 8.

04

Press ▶. Turn STYLE ON, try bank 1 or 2 (arpeggios), spin VARIATION until it rolls. SHIFT+E adds shuffle: instant house.

05

The wash: ENVELOPE up (long release), delay synced and audible, reverb big, FILTER closed to 9 o'clock, then open it over eight bars. That slow bloom is the Porter move.

06

SHIFT + WRITE → Ptn → confirm. Now it exists.

The chord sets worth knowing

SET 50The Porter set. House. Wall-to-wall maj7s and 9ths, all in one family. Live here first.
SET 53House, with the heartbreak chord built in: Cmaj7 → Em7 → Fmaj7 → Fm6. That major-to-minor melt is the most emotional move in pop.
SET 54Plain diatonic 7th chords in C. Instant classic progressions, nothing exotic.
SET 22A minor-9 chord on all twelve roots. The deep-house stab set. Two pads = a track.
SET 55–56Jazz House. 13ths, m11s, altered colors. When plain maj7 stops being enough.
SET 85 / 23maj7♯11 everywhere: the lydian shimmer. One chord, held, reverb up, filter sweeping = an entire intro.
SET 68Lo-fi R&B. Dark, gorgeous, borrowed chords. For the sadder cue.

Did you know

"The Royal Road" (王道進行, ōdō shinkō) is the actual Japanese name for progression No. 1: IVmaj7–V–iii–vi. It powers a huge share of J-pop and anime themes, which is exactly where Porter Robinson learned it. You are borrowing the same road.

Practice ladder · one rung a day

D1

Set 50 only, style off. Learn which pads love each other. Record one 4-chord loop and save it.

D2

Same loop, styles on. Audition all 12 variations of banks 1, 2, and 4. Notice how the same chords become different songs.

D3

Performance day: one loop, hands on FILTER and ENVELOPE the whole time. Build an 8-bar rise, then cut the filter at the top.

D4

Copy your pattern to a new slot, change the style and mood, and practice switching patterns while playing. That's an arrangement.

D5

New color: rebuild your best loop on set 53 and add the Fm6. Then try it transposed with SHIFT+A until it sits where it hurts.

Gotchas

  • Save or lose it. SHIFT + WRITE, every time. The J-6 forgets everything at power-off.
  • Style on changes the pads. If you want to hear the raw chord, turn STYLE ON off first.
  • Steps remember styles. If the groove changes mysteriously mid-loop, a step has its own style stamped on it. Select it, SHIFT+G clears it.
  • Ties need empty steps. Long sustained chords are written with HOLD in step edit, into steps with nothing in them.
  • The display shows numbers, not chord names. This page is your chord chart. Keep it on the phone.
  • Battery is ~4.5 hours. Red charge light = about 30 minutes left. USB-C, any power bank works.
  • No automation. Filter moves aren't recorded. They're a performance, every take. On camera, that's a feature.
